# D08-T04 — Typed ambiguous global-Intake placement Review

- **Outcome / owner / date:** D08-T04; current implementation task; 2026-09-15. A trusted, provider-independent placement evaluation can now create one typed `ambiguous_placement` Review for a ready global Intake PDF with at least two eligible active Matter destinations. Owner, Admin and Associate can choose one destination with a reason; Viewer remains read-only. The same transaction closes Review, canonically materialises the Intake as a document, records decision and Activity evidence, and returns the exact document/version for Workbench page 1 and Matter reopening.

The database re-derives organisation, global-Intake, immutable asset, PDF/page, Matter and Client facts. Runs, candidates, evidence and decisions are versioned and mutation-protected. Candidate Matter and Client revisions are snapshotted; Intake timestamp and asset hash, availability, MIME and validated-page facts are fenced. Relevant Intake, asset, Matter or Client change closes the item as source unavailable and releases ordinary Hub placement. Matter-origin Intake is rejected. The resolver requires an exact-active Review actor, expected revision, eligible snapshotted candidate, bounded reason and actor-bound idempotency; stale, mismatched and concurrent attempts fail closed.
