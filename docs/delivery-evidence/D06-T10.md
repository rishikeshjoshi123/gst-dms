# D06-T10 — Add Fit page sizing

**Owner task / date:** current implementation coordinator, 2026-09-08

**Base / implementation revision:** `5cd04de` / `90e7867`

**State:** review; local geometry, shared-consumer and design-system checks passed, while interactive browser, independent QA and deployment acceptance remain unverified.

The shared production `PdfViewer` now provides a visible Fit page mode alongside Fit width and manual zoom. A tested pure geometry model computes each page's scale from both available viewer dimensions and the page's rotated source geometry, preventing portrait or landscape pages from overflowing either axis. Full canvases and continuous-scroll placeholders use the same per-page scale.

The viewer's ResizeObserver now tracks usable height as well as width. Viewer resize, rotation, mode changes and opening or closing the thumbnail disclosure realign the active page through the viewer-owned scroller, preserving document context instead of inheriting a stale offset. Manual zoom exits both fit modes, and source changes return to the established Fit width default.

The reusable viewer documentation and `/dev/design-system` reference now include Fit page and its two-dimensional context-preservation contract. Controls retain visible labels, pressed-state semantics, shared buttons, semantic tokens and effective 44-pixel targets.

Developer evidence passed: seventeen focused behavioral and source-contract tests cover rotated two-dimensional fit scale, resize observation and active-page preservation plus existing bounded thumbnails, native-text search, rotation, keyboard navigation, continuous rendering, placeholder geometry, selection attribution and canonical consumers. TypeScript, changed-file ESLint, whitespace validation and the exact webpack production build pass. The successful build emitted the existing Supabase Node-version deprecation warning but no build failure.

Interactive browser QA remains unavailable because the Mac is locked. Actual mixed-size PDF geometry, resize, thumbnail-open transitions, rotation, 320/360 px, short-height layout, touch, dark mode and 200% zoom remain unverified. Independent QA and deployment acceptance remain open. D06 still retains distinct source failure states, OCR-integrated search, selective Realtime and downstream Workbench-consumer acceptance.
