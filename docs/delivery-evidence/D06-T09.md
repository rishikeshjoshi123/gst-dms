# D06-T09 — Add bounded synchronized PDF thumbnails

**Owner task / date:** current implementation coordinator, 2026-09-08

**Base / implementation revision:** `a9780fc` / `0a8d1a8`

**State:** review; local bounded-thumbnail, shared-consumer and design-system checks passed, while interactive browser, independent QA and deployment acceptance remain unverified.

The shared production `PdfViewer` now offers a visibly labelled Show/Hide thumbnails disclosure. Its horizontal navigator sits outside the vertical PDF body scroller, so opening it does not add another vertical scroll owner or move application chrome. The current page uses `aria-current="page"`; selecting a thumbnail, Earlier pages or Later pages uses the same clamped, scroller-local page request path as direct entry, search results and keyboard navigation.

The thumbnail model is bounded for long documents. It exposes at most the current page and two neighboring pages on either side, so at most five thumbnail entries and five thumbnail canvases exist at once. Explicit earlier/later controls advance the window without constructing one DOM button per document page. The selected thumbnail is recentred inside only the horizontal strip, and source changes clear thumbnail references and collapse the disclosure. Rotation is applied consistently to full pages and thumbnails.

The reusable viewer contract and `/dev/design-system` static reference now document bounded native-text search, the horizontal thumbnail disclosure, its canvas limit and its scroll ownership. The implementation uses shared buttons, semantic tokens, visible disclosure labels, programmatic page labels, keyboard-native buttons, visible focus styling and effective 44-pixel targets.

Developer evidence passed: fifteen focused behavioral and source-contract tests cover the five-thumbnail window at document boundaries, current-page semantics, earlier/later navigation, horizontal synchronization, existing 25-page text search, safe highlighting, responsive controls, rotation, keyboard navigation, the five-canvas continuous document window, placeholder geometry, selection attribution and canonical consumers. TypeScript, changed-file ESLint including the gallery, whitespace validation and the exact webpack production build pass. The successful build emitted the existing Supabase Node-version deprecation warning but no build failure.

Interactive browser QA was attempted, but the Mac remains locked. Actual thumbnail rendering, rapid window changes, horizontal touch/keyboard behavior, rotation, 320/360 px wrapping, short-height layout, dark mode and 200% zoom remain unverified. Independent QA and deployment acceptance remain open. D06 still retains Fit page, OCR-integrated search, selective Realtime and downstream Workbench-consumer acceptance.
